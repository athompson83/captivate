# Feature Specification

## Library

- Presentation grid/list with search, tags, folders/collections, sort, favorites, recent activity, duplicate, archive, and trash.
- Lecture notes stored as first-class searchable content.
- Reusable asset library for images, video, audio, diagrams, icons, themes, and saved scene patterns.
- Version history and restore.

## New presentation

Creation paths:

- Start blank.
- Start from a professionally designed template/system.
- Generate from prompt.
- Generate from outline/source documents.
- Import an existing presentation/document and convert into Captivate scenes.
- Reuse/duplicate a previous presentation.

AI creation should ask only high-value questions: audience, goal, duration, tone, content depth, and source constraints. It should generate a structured scene plan before expensive media generation.

## Studio / Edit mode

- Scene navigator with drag reorder, sections, grouping, duplicate, hide, and branch support.
- Insert control between any scenes/sections.
- Responsive scene canvas rather than a fixed slide-only model.
- Blocks: heading, rich text, image, video, audio, quote, data visualization, diagram, code, callout, embed, interactive question, divider, and custom layout group.
- Direct manipulation with alignment, spacing, sizing, layering, and responsive layout controls.
- Theme tokens for typography, color, surface, spacing, radius, animation character, and media treatment.
- Animation timeline/reveal sequencing.
- Undo/redo and autosave.
- Keyboard shortcuts and command palette.
- Comments/collaboration later without coupling core authoring to realtime presence.

## Notes

### Speaker notes
Private, scene-linked notes for live delivery. AI may draft them; users can edit freely.

### Lecture notes
Long-form notes associated with a presentation, course, or topic. They should support headings, rich text, links, media references, search, and future export. Lecture notes are not merely speaker notes concatenated together.

## Presenter mode

- Audience output in a separate clean window/screen with no browser/editor chrome.
- Current/next scene previews.
- Movable/resizable private speaker-notes panel.
- Notes automatically follow the active scene/beat.
- Total presentation timer and current-scene timer.
- Laser pointer mode.
- Spotlight/highlight-under-pointer behavior.
- Click/drag transient highlight for a word/image/region.
- Freehand drawing with compact palette, eraser/undo, and clear-all.
- Presenter controls never visible to the audience unless intentionally shared.
- Keyboard/remote-friendly navigation.
- Pause/black-screen and jump-to-scene tools.

## Recording

- Capture audience presentation output.
- Capture microphone.
- Optional camera capture with selectable layout/position.
- Presenter controls excluded from final recording by default.
- Pause/resume and elapsed-time state.
- Recoverable recording workflow where feasible; avoid losing an entire session because one upload/export step fails.
- Export/shareable video workflow.

## AI assistance

- Presentation outline generation.
- Scene generation/rewrite at local scope.
- Tone, reading level, detail, and duration adjustments.
- Speaker-note generation.
- Lecture-note assistance.
- Image/diagram suggestions and generated assets.
- Theme/layout recommendations.
- Source-aware fact checking and citation support where appropriate.
- “Use my image” versus “find/generate a similar image” choice for supplied media.

## Organization and discovery

- Search across titles, scene text, lecture notes, speaker notes, tags, and assets.
- Categories/collections.
- Recently edited and recently presented.
- Templates and personal reusable blocks.

## Later / advanced

- Live audience participation/polls.
- Shared presenter/co-presenter mode.
- Realtime collaboration.
- Branching/nonlinear presentations.
- LMS/embed integrations.
- Public share links and analytics.
- PDF/PPTX import/export fidelity improvements.
- Remote presenter app/phone controller.
